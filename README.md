# Мини Dice Wars (Canvas, без фреймворков)

## Что это
Мини-стратегия в стиле Dice Wars на чистых **HTML/CSS/JS**.

- запуск: просто открыть `index.html` (или через любой статический сервер)
- карта: загрузка из `countries.geojson` / `world.geojson` / `map.json`
- рендер: `<canvas>`
- игроки: человек + простой ИИ

## Особенность карты
Для GeoJSON используется **азимутальная равнопромежуточная проекция в стиле ООН**:
- центр проекции: Северный полюс
- видимая область ограничена примерно до 60° ю.ш.
- получается круглая «эмблемная» карта мира

## Быстрая проверка после загрузки на хостинг
1. Откройте страницу игры.
2. Нажмите кнопку **«Проверка»**.
3. Должно появиться сообщение `Проверка ОК`.

Если проверка не проходит:
- убедитесь, что рядом с `index.html` лежит `countries.geojson` (или `world.geojson`/`map.json`)
- проверьте консоль браузера (F12)

## Почему может не открываться GitHub Pages
Для репозитория `chat_GPT1` правильный URL обычно:

`https://kardinalmarkov.github.io/chat_GPT1/`

Если 404:
- проверьте в `Settings -> Pages`, что выбран `main` и папка `/(root)`
- дождитесь деплоя (1–5 минут)
- обновите страницу без кэша (Ctrl+F5)

## Локальный запуск (рекомендуется)
Из корня проекта:

```bash
python -m http.server 8000
```

Далее открыть:

`http://127.0.0.1:8000`
