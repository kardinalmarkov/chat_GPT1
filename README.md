# Мини Dice Wars (Canvas, без фреймворков)

## Что изменено
- Игра теперь стабильно запускается на GitHub Pages.
- Карта теперь **обычная мировая (прямоугольная), не Глисона**.
- На карте ровно **12 стран**: ядерные + крупные.

Состав 12 стран:
1. USA
2. Russia
3. China
4. India
5. Pakistan
6. France
7. United Kingdom
8. Israel
9. North Korea
10. Iran
11. Germany
12. Brazil

## Загрузка карты
Порядок загрузки:
1. `countries.geojson` (основной файл, лежит в репозитории)
2. встроенная карта на 12 стран (автоматически)

Даже если файл не загрузился, игра стартует на встроенной карте.

## GitHub Pages
Для вашего репозитория рабочий URL:

`https://kardinalmarkov.github.io/chat_GPT1/`

Если видите старую/пустую версию:
- откройте `Settings -> Pages`
- убедитесь, что выбрана нужная ветка
- подождите деплой 1–5 минут
- сделайте Ctrl+F5

## Локальный запуск
```bash
python -m http.server 8000
```
Открыть: `http://127.0.0.1:8000`


## Фон остальных стран и как не перегрузить игру
- Добавлен неигровой фон континентов (серые полигоны) — карта воспринимается как полноценная мировая.
- Игровыми остаются 12 стран: это сохраняет быстрый темп и читаемость.
- Добавлен лёгкий инфо-слой точек: `NATO/США базы` и `Партнёры США в АТР` (только визуальная аналитика, без усложнения правил).

### Идеи на следующий шаг (без перегруза)
1. Давать +1 к подкреплению за контроль 2+ стран в одном инфо-кластере.
2. Включить опцию "режим альянсов" отдельным переключателем (по умолчанию выключен).
3. Показывать всплывающую справку по стране (наведение), не влияя на базовый бой.
